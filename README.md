## 📌 Overview

**TaskFlow** is a simple and modern To-Do List web application built using **HTML, CSS, and JavaScript**.
It allows users to **add, edit, and delete tasks** with data saved locally using **Local Storage**.
The interface is clean, responsive, and designed for a smooth user experience.

## 🚀 How to Run Locally

**Step 1 — Clone the repository:**
```bash
git clone https://github.com/asmashahzadi764-alt/taskflow-todo.git
```

**Step 2 — Open the project folder:**
```bash
cd taskflow-todo
```

**Step 3 — Open in browser:**
```
Simply open index.html in any browser — no server required!
```

---

## 🧭 How It Works

```
User opens the app
       ↓
Types a task and clicks Add
       ↓
Task appears in the list & saved to Local Storage
       ↓
User can Edit (modal popup) or Delete any task
       ↓
Tasks persist even after page refresh ✅
```
